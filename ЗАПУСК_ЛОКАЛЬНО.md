# Локальный запуск RSW

## Требования

- Windows 10/11
- Node.js LTS (используется только для инструментов разработки и сборки)

## Запуск

1. Установите Node.js LTS с https://nodejs.org/, если он ещё не установлен.
2. Распакуйте проект в отдельную папку.
3. Дважды щёлкните по файлу `start-local.bat`.
4. При первом запуске скрипт установит зависимости.
5. Откройте http://localhost:5173.

Для открытия сайта на телефоне подключите его к той же Wi-Fi-сети, узнайте IPv4-адрес компьютера командой `ipconfig` и откройте `http://АДРЕС-КОМПЬЮТЕРА:5173`. Если Windows запросит разрешение брандмауэра, разрешите доступ для частной сети.

## Что изменено

- Интерфейс переведён на статическую клиентскую архитектуру: каталог, бренды, карточки товаров и фильтры используют данные из `src/data/streetwearData.ts`.
- Удалён Express API и серверный файл `server.ts`.
- Заявки формы «Для брендов» сохраняются в локальном хранилище браузера на текущем устройстве. Они **не отправляются** владельцу сайта автоматически.
- Избранное также хранится локально в браузере.

## Сборка

Команда `npm run build` создаёт статический сайт в папке `dist`. Для локального просмотра собранной версии выполните `npm run preview` и откройте адрес, который покажет Vite (обычно http://localhost:4173).

Собранный сайт не требует Express или отдельного API. Для открытия файлов через браузер используется только раздача статических файлов; запускать собственный сервер приложения не нужно.

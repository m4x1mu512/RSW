# Публикация RSW через GitHub Pages

Для сайта настроена автоматическая публикация через GitHub Actions.

## Как включить сайт

1. Сначала объедините pull request с изменениями в ветку `main`:
   https://github.com/m4x1mu512/RSW/pull/1
2. Откройте репозиторий **Settings → Pages**.
3. В разделе **Build and deployment** установите **Source: GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь успешного выполнения задания **Deploy to GitHub Pages**.

После успешной публикации сайт будет доступен по адресу:

https://m4x1mu512.github.io/RSW/

При каждом следующем push в `main` GitHub Actions автоматически соберёт и опубликует актуальную версию сайта. Повторно запускать локальный сервер или загружать папку `dist` вручную не потребуется.

## Важно

- GitHub Pages публикует статическую версию сайта. Отдельный сервер и Node.js для посетителей не нужны.
- Маршрутизация сайта использует HashRouter, поэтому внутренние страницы открываются по ссылкам с `#` и не требуют серверной настройки.
- Заявки из формы бренда в текущей статической версии сохраняются только в localStorage браузера посетителя и автоматически владельцу сайта не отправляются.
